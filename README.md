# assets-zype-hps

Contenido editorial, assets y skill de los Reels de ZYPE + Hitch Point Studio.

- El notebook de Colab `Crear_video_ZYPE_HPS_v2.ipynb` lee `editorial/`, escribe el guion, lo locuta y sube `guion.txt`, `locucion.wav` y `palabras.json` a `briefs/<AAAAMMDD-HHMM>/`.
- Claude dirige y renderiza el video con la skill `.claude/skills/zype-reel/` (instrucciones generales en `CLAUDE.md`).
- Este repo es la única fuente de verdad: los assets se añaden y editan aquí directamente.

Carpetas: `editorial/` (marca, ADN, temas, datos, prompts) · `icons/` · `logos/` · `ui/` · `illus/` · `textures/` · `fonts/css/` · `brand/` (paletas) · `scripts/` · `briefs/` · `contactos.png` (vista de todos los assets gráficos).
